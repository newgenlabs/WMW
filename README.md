# Whitestone Marble Setters

Static, dependency-free website. Open `index.html` in a browser or host the folder anywhere.

**Interactive features:** floor pattern visualizer (6 stones, 5 layouts, grout/finish/tile size), instant cost estimator, before/after slider, filterable project gallery with preview dialog, process tabs, testimonial rotator, searchable FAQ, validated quote form (saved to `localStorage` + prefilled email).

**Customise:** edit `CONFIG` (phone/email), pricing tables (`STONES`, `PATTERNS`, `TYPES`), and content arrays at the top of `app.js`. Prices, testimonials, stats and the phone/email are placeholders.
